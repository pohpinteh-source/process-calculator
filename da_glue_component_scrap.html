📖 Quick Guide

Calculator Function
  • Estimate expected DA glue component scrap.
  • Calculate glue waste based on actual production usage.
  • Check whether available glue volume can support production within pot life.
  1. Enter Volume per Syringe (Vol/Syringe, g).
  2. Enter Quantity of Syringes per Machine.
  3. Total Volume (g) will be calculated automatically.
  4. Enter Glue Pot Life (hours).
  5. Enter Production Rate (UPH).
  6. Enter Machine Utilization (MU %).
  7. Input 3 actual QPA measurements (3x QPA, g).
  8. Average QPA will be calculated automatically.
  9. Component Scrap (%) and Component Scrap (g) will be calculated automatically.
  10. Negative scrap result (red color) indicates available glue volume is insufficient for the required consumption.
  11. Use the image as reference for QPA calculation.
  12. Only enter values in yellow highlighted cells.
  13. Click Clear to reset all inputs.
  14. Click Back to return to Home Page.
