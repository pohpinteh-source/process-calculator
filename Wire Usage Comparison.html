📖 Quick Guide

Calculator Function
  • This calculator provides a wire consumption comparison between Existing Product and New Product.
  • Identify potential wire saving or increased wire consumption for new package designs.
  • Support package cost evaluation and wire material consumption estimation.
  • Assist engineering qualification and package design comparison before production release.
  1. Enter all Existing Product values in the left column and New Product values in the right column.
  2. Only enter values in the yellow highlighted cells.
  3. Require information:
    • Number of Dies
    • LED & ESD Wire Qty
    • LED & ESD Die Thickness
    • Wire Size
    • LED & ESD Loop Height
    • Ball / Bump Size & Height
    • 2D Wire Distance
  4. Total Wire Length (3D) for Existing & New Product is calculated automatically.
  5. Differences (%) indicates wire usage change between New Product and Existing Product.
  6. Positive (%) result indicates higher wire consumption.
  7. Negative (%) result indicates lower wire consumption.
  8. Refer to the Wire Usage drawing at the bottom of the page for parameter definition.
  9. Click Clear to reset all values.
  10. Click Back to return to Home Page.
