📖 Quick Guide

Calculator Function
  • Provide recommended production Die Shear specification values.
  • Calculate Die Shear Force requirements based on MIL-STD-883 guidelines.
  • Generate 1.0x, 2.0x, 2.0x+14% and 2.0x+25% Die Shear Force values automatically.
  • Support Die Shear specification definition and product release activities.
  1. Enter Chip Size, X [mm].
  2. Enter Chip Size, Y [mm].
  3. Only enter values in yellow highlighted cells.
  4. Dimensions will automatically convert from mm to inch.
  5. Chip area will be calculated automatically.
  6. 1.0x, 2.0x, 2.0x+14%, and 2.0x+25% Die Shear Force values will be calculated automatically.
  7. 2.0x [gf] is the target value.
  8. 2.0x+25% [gf] is recommended for production usage.
  9. Roundup value can be used as specification reference.
  10. Click Die Shear Spec MIL883 for reference.
  11. Click Clear to reset all values.
  12. Click Back to return to Home Page.
