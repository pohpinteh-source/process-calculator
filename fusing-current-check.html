Remark #1:
Fusing Current (A) & Current carrying capacity values are estimated using analytical equations.

Remark #2:
Preece and Modified Preece equations are provided for reference purposes only.

Remark #3:
Actual current carrying capability may vary depending on wire geometry, package structure, molding compound, and operating environment.

Remark #4:
Physical validation is recommended before engineering or production use.

Remark #5:
Operating CCC is the primary value for wire-size selection. Design CCC is for benchmark comparison. Extreme Stress CCC is for thermal-stress comparison only and shall not be used as the product operating limit.
