📖 Quick Guide

Calculator Function
  • Provide standard Bond Parameter references for machine setup.
  • Support initial Shinkawa wire bond parameter setup and optimization activities.
  • Reduce setup time and improve parameter selection consistency.
  1. Enter Wire Size, Target Ball Size & Target Bump Size (μm).
  2. Only enter values in the yellow highlighted cells.
  3. Ball & Bump Bond's Search Force and Bond Force are calculated automatically.
  4. 2nd Bond Force is automatically determined based on Wire Size.
  5. Refer to US Power table for recommended ultrasonic setting.
  6. Refer to Search Speed table based on Target Ball Size.
  7. Use Bond Parameter table as initial setup reference.
  8. Final machine parameter must be optimized and verified during bonding process.
  9. Click Clear to reset all inputs.
  10. Click Back to return to Home Page.
